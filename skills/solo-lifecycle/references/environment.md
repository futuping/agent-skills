# Nix环境与可重复执行

00只盘点环境文件、能力状态和缺口；实际建立、显式加载、命令执行与工程管线验证属于06。已配置不等于可用；无项目时不为完成00创建Nix环境。既有环境的低风险只读核查按授权进行，不凭空重复初始化。

只执行当前任务适用的活动。公共授权、状态与预算规则见SKILL.md；无需重复加载其他阶段。

## 06 工程环境与交付管线准备

**进入：**首次命令执行、接入旧仓库、工具缺失、锁文件/CI变化或环境疑似漂移。

**判断：**现有项目/父目录哪个Nix环境权威？运行时与包管理器由哪些锁固定？测试/构建入口是什么？命令会写哪里、连接什么？

**分工：**人维护机器级授权及托管配置；agent只读检查项目和父目录、选择匹配环境并在授权范围运行；Nix、项目锁、CI和制品摘要给出可追溯环境。

**执行：**检查AGENTS/CLAUDE/README、工作区、清单、锁、CI、flake.nix/flake.lock/.envrc/shell.nix；保留版本和包管理器。工具链由Nix，应用依赖由原机制。缺环境时读取现有nix-direnv函数定义，显式目标后才初始化；未知函数签名不猜。确认direnv未回退旧环境。

**最小产物：**在工作记录保存环境来源、选择命令、关键版本、锁摘要、构建测试入口及权限。新模板通过不代表项目通过。秘密只记录名称/来源不记录值。

**验证：**在正确环境中实际获得版本并执行适用的基线构建/测试；记录工作树差异和生成制品来源。无法加载Nix时状态为阻塞/待验证，不能用另一套Python/Node结果冒充。

**返回与停止：**工具版本冲突回现有环境选择；项目约束不可能满足回02/05。CI基线已有失败先分离既有问题与本次回归。 不认识的初始化函数、未授权.envrc/shellHook、全局托管链接冲突，停止该写入/执行；可继续分析和准备补丁。


## 环境的具体动作

先读取实际权威指令，再检查当前目录与相关父目录中的 `AGENTS.md`、适用的 `CLAUDE.md`、README、清单与锁、CI、`flake.nix`、`flake.lock`、`.envrc`、`shell.nix`。`git status --short`是观察，不是允许丢弃用户修改。版本身份包含未提交diff/文件摘要，不只HEAD。

优先用适合本项目的既有项目/父目录shell。先审查`.envrc`及其加载脚本、flake/shellHook的副作用，再按已有授权使用。`direnv allow`意味着允许执行代码，不是安全扫描。检查`NIX_DIRENV_DID_FALLBACK`和加载日志；回退旧devShell时不能把结果当新环境验证。

可采用的执行形态（工作目录及shell名称以实际仓库为准，不盲抄占位）：

```sh
# 已进入项目目录且现有.envrc已被审查/授权时：
direnv exec . sh -c 'command -v node; node --version'
# 项目flake确有默认devShell且已审查时：
nix develop . --command sh -c 'command -v node; node --version'
```

以上只展示选择/核验方式，不指定项目必须使用Node。实际命令改为既有语言工具和项目测试入口。若父目录提供shell，使用它的真实路径和输出名。命令不存在先检查环境选错、shell不适用或锁变更，不改用系统运行时/全局安装来制造“通过”。环境执行失败时报告阻塞，继续不依赖运行时的分析。

### 缺失环境

用户的`nix-direnv`初始化函数不是本技能提供的命令协议。先以只读方式检查可见函数，如当前shell中的 `type nix-direnv`，以及项目说明/现有定义；不要为探测而source未知启动脚本。识别函数实际签名后，明确选择匹配目标node、bun、python、go或rust，再在授权范围初始化。签名或模板来源不可核时，交付目标、保留版本、锁与建议改动清单，阻塞初始化，不能猜造 `nix-direnv init ...`。

初始化后的flake只是起点；根据真实运行时、依赖和CI调整，并运行项目真实检查。不要因模板测试通过宣称应用通过。工具链由Nix提供，应用依赖仍由项目现有包管理器及锁管理；安装项目依赖会有网络/构建脚本副作用，须在任务授权内且保留锁。

### 机器级边界

机器级配置由`~/.nix/nix-darwin`管理。文档使用`~`，shell使用正确引用的`"$HOME/..."`（实际命令中去掉展示性反斜线），Nix使用既有配置值或相对源码路径。不得独立运行npm全局安装、用户级pip、brew install、nix profile install或运行时引导脚本；不得把nix-rebuild用作日常项目修复。临时只读任务可复用适当Nix环境/现有固定输入，不为一次计算创建新项目或使用未固定latest输入。

全局共享源`~/.nix/nix-darwin/dotfiles/agents/AGENTS.md`及其Home Manager托管入口只读复用；本技能不重写它。需要环境修改时在项目范围提出最小diff，机器级更改单列并保留原授权边界。
